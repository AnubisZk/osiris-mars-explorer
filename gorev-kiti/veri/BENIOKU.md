# veri/ klasörü

Veri Atölyesi'nde (`../veri-atolyesi.html`) eğittiğiniz **atmosfer modellerini** (`.json`) buraya koyun
ve `ayarlar.js`'te şöyle bağlayın:

```js
atmosfer: { model: 'veri/jezero-atmosfer.json', saat: 10 },
```

Ham ölçüm dosyalarını (MEDA `.csv`) buraya koymanız gerekmez; model dosyası tek başına yeter.
Ayrıntılar: `../VERI-IKIZI.md`
